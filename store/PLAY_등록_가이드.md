# Google Play 등록 가이드 — 3단계 단어장

이 폴더에 든 것
- `vocab3-v1.3.aab` — Play에 올리는 파일 (Android App Bundle, targetSdk 36 = 2026-08-31 이후 신규 앱 요건 충족, 업로드 키로 서명 완료)
- `store_listing.md` — 앱 이름/설명/앱 설정 항목 답변 (복사용)
- `privacy_policy.html` — 개인정보처리방침 (공개 URL에 올려서 주소를 입력)
- `graphics/` — 아이콘 512, 그래픽 이미지 1024×500, 스크린샷 1080×1920 9장
- `keystore/vocab3.jks` — 업로드 키 (alias `vocab3`, 비밀번호 `vocab3-2026`). **분실하면 업데이트를 못 올리니 따로 백업.**

## 0. 미리 알아둘 것 (2026-09 기준)
- 개발자 계정: 일회성 US$25, 신분증·결제 프로필·전화 인증 필요. 승인 1~3일.
- 2023-11-13 이후 만든 **개인 계정**은 프로덕션(정식 출시) 전에 **비공개 테스트에서 테스터 12명이 14일 연속 참여**해야 하고, 그 뒤 "프로덕션 액세스 신청" 심사(약 7일)를 통과해야 합니다.
- **내부 테스트** 트랙은 이 조건 없이 즉시 사용 가능(최대 100명, 링크로 초대). 본인·가족·동료 폰에 Play 스토어로 설치하는 목적이면 내부 테스트만으로 충분합니다.
- 신규 앱은 Android 16(API 36) 이상 타겟 필수 → 이 AAB는 충족.

## 1. 개발자 계정 만들기
1. https://play.google.com/console 접속 → 개인 계정 선택 → 결제(US$25) → 신분증 인증, 전화·이메일 인증.
2. 승인 메일이 오면 콘솔 진입.

## 2. 앱 만들기
1. 콘솔 홈 → **앱 만들기** → 앱 이름 `3단계 단어장`, 기본 언어 한국어, 앱, 무료 → 선언 사항 체크 → 만들기.
2. 대시보드에 "앱 설정" 할 일 목록이 뜹니다. `store_listing.md` 하단 표대로 답변하세요.
   - 개인정보처리방침: `privacy_policy.html`을 공개 주소에 올린 뒤 URL 입력 (GitHub Pages, Notion 공개 페이지, 개인 홈페이지 등 아무 곳이나 가능).
   - 데이터 보안: "수집·공유 안 함".
   - 콘텐츠 등급: 설문 → 전체이용가.
   - 타겟층: 18세 이상.
3. **스토어 등록정보** → 이름/짧은 설명/자세한 설명 붙여넣기, `graphics/` 이미지 업로드.

## 3. 바로 설치해서 쓰기 — 내부 테스트 (권장 첫 단계)
1. 왼쪽 메뉴 **테스트 > 내부 테스트** → 새 버전 만들기.
2. 앱 서명: "Google에서 생성한 키 사용" 그대로 진행 (Play App Signing). 우리가 서명한 키는 자동으로 업로드 키가 됩니다.
3. `vocab3-v1.3.aab` 업로드 → 출시 노트 붙여넣기 → 저장 → 버전 검토 → 내부 테스트로 출시 시작.
4. 테스터 탭 → 이메일 목록 만들기(본인 Gmail 포함) → 저장 → "링크 복사" → 그 링크를 폰에서 열어 참여 → Play 스토어에서 설치.
   (내부 테스트는 심사 없이 몇 분 안에 반영됩니다.)

## 4. 정식 출시까지 가려면 — 비공개 테스트 → 프로덕션
1. **테스트 > 비공개 테스트** → 트랙 만들기 → 같은 AAB 업로드 → 테스터 이메일 12명 이상 등록(또는 Google 그룹) → 출시.
2. 테스터들이 참여 링크로 옵트인한 뒤 **14일 연속** 유지되어야 합니다(중간에 나가면 그 사람은 다시 처음부터).
3. 14일 후 대시보드에 **프로덕션 액세스 신청** 버튼이 뜹니다. 테스트 과정·피드백·앱 설명을 묻는 3개 항목을 작성 → 제출 → 약 7일 내 결과 메일.
4. 승인되면 **프로덕션** 트랙 → 국가 선택(대한민국 또는 전체) → AAB 업로드 → 검토 제출. 심사 후 스토어에 공개됩니다.

## 5. 업데이트 올리기
1. `AndroidManifest.xml`의 `versionCode`를 1 올리고(`versionName`도), `./build.sh` 실행 → `build/vocab3.aab`.
2. 콘솔에서 해당 트랙에 새 버전 만들기 → AAB 업로드 → 출시.
3. 반드시 같은 `keystore/vocab3.jks`로 서명해야 합니다 (build.sh가 자동 처리).

## 자주 막히는 곳
- "타겟 API 레벨" 경고 → 이 AAB는 36이라 해당 없음. 이후 매년 8월 말에 요구 레벨이 올라가니 그때 한 번씩 재빌드.
- 스크린샷 규격 오류 → 1080×1920 PNG(알파 없음)로 준비돼 있음. 최소 2장.
- 개인정보처리방침 URL 없이는 심사 제출이 안 됨.
- 계정 정보(이름·이메일)가 스토어에 공개되는 "개발자 이름"은 계정 설정에서 변경 가능.
