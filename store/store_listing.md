## 자세한 설명 (4000자 이내)
```
뜻만 외우고 끝나는 단어 공부는 그만. 3단계 단어장은 "예문을 입 밖으로 말할 수 있는가"를 기준으로 단어를 세 개의 단어장 사이에서 옮겨 가며 완전히 내 것으로 만드는 앱입니다.

■ 3단계 단어장 시스템
1단계 새 단어장 — 매일 새 단어 20개(변경 가능)와 예문이 자동으로 채워집니다.
2단계 외운 단어장 — 단어와 예문이 자연스럽게 나오면 오른쪽으로 넘겨 2단계로. 주기적으로 복습합니다.
3단계 완전 암기장 — 복습까지 통과한 단어를 최종 점검하고, 통과하면 졸업 처리합니다.

■ 이렇게 공부해요
· 카드 한 장에 단어 · 뜻 · 예문 · 해석. 뜻과 예문은 가려져 있어 먼저 떠올린 뒤 탭해서 확인합니다.
· 예문 칸은 탭할 때마다 영어 → 해석 → 가림 순서로 바뀝니다.
· 위로 스와이프 = 외웠다(다음 단계로), 아래로 = 아직(현재 단계 유지), 좌우 = 이전·다음 카드. 실수하면 되돌리기.
· 한→영 모드: 우리말 뜻과 해석만 보고 영어 단어와 예문을 말해 보는 출력 훈련.
· 발음 듣기와 자동 발음(카드가 나올 때 단어, 영어 예문이 보이는 순간 예문 재생).
· 상단 진행 바(1/20)로 오늘 목표를 부담 없이 소화. 연속 학습일 표시.
· 듣기 복습: 단어 → 잠깐 대기 → 영어 예문 천천히 여러 번 → 우리말 뜻 순서로 읽어 줘요. 화면을 꺼도, 내비게이션을 켜도 계속 재생되고 알림에서 조작할 수 있어 이동 중에 귀로 복습하기 좋아요. 읽는 횟수·속도·대기 시간은 설정에서 조정.

■ 내 단어로 채우기
· 회화 필수 표현 200개(일상·업무·여행·감정·날씨 등 10테마)가 기본으로 들어 있습니다.
· 단어를 직접 추가하거나 "단어 | 뜻 | 예문 | 해석" 형식으로 여러 줄을 한 번에 붙여넣어 가져올 수 있습니다.
· 예문을 길게 누르면 바로 수정할 수 있고, 내 Gemini API 키를 넣으면 AI가 상황에 맞는 새 예문을 써 줍니다(선택).
· 백업 파일 저장/복원, 텍스트 공유, 다크 모드, 통계, 하루 목표(10/20/30/50) 설정.

■ 가볍고 안전하게
· 회원가입 없음, 광고 없음, 학습은 인터넷 없이 됩니다.
· 모든 데이터는 내 기기 안에만 저장됩니다. 선택 기능인 AI 예문 생성(내 Gemini API 키 사용)을 누를 때만 그 단어 정보가 Google Gemini로 전송됩니다.
```

### 데이터 보안(Data safety) 세부
- "앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?" → **아니요**
- 이유: 앱에 자체 서버가 없고 학습 데이터는 기기 내부 저장소(SharedPreferences)에만 저장됩니다. 백업 파일은 사용자가 직접 선택한 위치에만 저장됩니다. 선택 기능인 AI 예문 생성은 사용자가 입력한 본인 Gemini API 키로 Google API를 직접 호출하며(개발자 서버 경유 없음), 개발자는 어떤 데이터도 받지 않습니다. → Data safety에서 "앱 기능" 목적의 "기타 데이터(단어·예문 텍스트)" 공유가 사용자 선택으로 발생한다고 적는 것이 안전합니다.
- 사용 권한: INTERNET(AI 예문 생성 시 Gemini API 호출 전용), VIBRATE(햅틱), 듣기 복습용 포그라운드 서비스(FOREGROUND_SERVICE_MEDIA_PLAYBACK)·알림(POST_NOTIFICATIONS)·WAKE_LOCK.
