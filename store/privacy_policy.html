3단계 단어장 개인정보처리방침

시행일: 2026년 9월 18일 (개정: 2026년 9월 20일)

1. 수집하는 개인정보

「3단계 단어장」(이하 "앱")은 어떠한 개인정보도 수집하지 않습니다. 회원가입, 로그인, 계정 연동 기능이 없으며, 이름·이메일·기기 식별자·위치 정보 등을 요청하거나 저장하지 않습니다.

2. 데이터 저장 위치

사용자가 앱에 입력한 단어, 예문, 학습 기록, 설정값은 오직 사용자의 기기 내부 저장소에만 저장됩니다. 앱에는 자체 서버가 없으며, 아래 "AI 예문 생성" 기능을 사용자가 직접 실행할 때를 제외하면 어떤 데이터도 외부로 전송되지 않습니다.

2-1. AI 예문 생성 (선택 기능)

사용자가 설정에 본인의 Google Gemini API 키를 입력하고 "AI 새 예문" 버튼을 누르면, 그 순간에만 해당 단어·뜻·기존 예문·사용자가 적은 요청 문구가 Google의 Gemini API(generativelanguage.googleapis.com)로 전송되어 새 예문을 받아옵니다. 전송된 내용의 처리는 Google의 Gemini API 이용약관과 개인정보처리방침을 따릅니다. API 키는 사용자의 기기 내부 저장소에만 저장되며 백업 파일에도 포함되지 않습니다. 키를 입력하지 않으면 앱은 네트워크에 접속하지 않습니다.

3. 백업 파일

사용자가 "백업 파일 저장" 기능을 사용하면 학습 데이터가 사용자가 직접 선택한 위치(기기 저장소 또는 클라우드 드라이브 앱)에 JSON 파일로 저장됩니다. 이 파일의 보관과 공유는 전적으로 사용자가 관리합니다.

4. 사용하는 기기 기능 및 권한

  • 인터넷(INTERNET): 선택 기능인 AI 예문 생성에서 Google Gemini API를 호출할 때만 사용합니다. 광고·분석·추적 목적의 통신은 없습니다.
  • 진동(VIBRATE): 카드를 넘길 때 짧은 햅틱 피드백을 주기 위해 사용합니다.
  • 포그라운드 서비스·알림·절전 방지(FOREGROUND_SERVICE_MEDIA_PLAYBACK, POST_NOTIFICATIONS, WAKE_LOCK): 듣기 복습을 화면이 꺼진 상태에서도 이어서 재생하고 알림으로 제어하기 위해서만 사용합니다.
  • 텍스트 음성 변환(TTS): 기기에 설치된 음성 엔진으로 단어와 예문을 읽어 줍니다. 앱이 음성 데이터를 저장하거나 전송하지 않습니다.

5. 제3자 서비스, 광고, 분석

앱에는 광고, 분석(애널리틱스) 도구, 제3자 SDK가 포함되어 있지 않습니다.

6. 아동의 개인정보

앱은 어떠한 사용자로부터도 개인정보를 수집하지 않으므로 아동의 개인정보 역시 수집하지 않습니다.

7. 데이터 삭제

앱 설정의 "전체 초기화"를 실행하거나 앱을 삭제하면 기기에 저장된 모든 데이터가 삭제됩니다.

8. 방침 변경

본 방침이 변경되는 경우 이 페이지에 게시하며, 시행일을 갱신합니다.
