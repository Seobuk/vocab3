3단계 단어장 개인정보처리방침

시행일: 2026년 9월 18일 (개정: 2026년 9월 22일)

1. 수집하는 개인정보

「3단계 단어장」(이하 "앱")은 어떠한 개인정보도 수집하지 않습니다. 회원가입, 로그인, 계정 연동 기능이 없으며, 이름·이메일·기기 식별자·위치 정보 등을 요청하거나 저장하지 않습니다.

2. 데이터 저장 위치

사용자가 앱에 입력한 단어, 예문, 학습 기록, 설정값은 오직 사용자의 기기 내부 저장소에만 저장됩니다. 앱에는 자체 서버가 없으며, 아래 "AI 예문 생성" 기능을 사용자가 직접 실행할 때를 제외하면 어떤 데이터도 외부로 전송되지 않습니다.

2-1. AI 예문 생성 (선택 기능)

사용자가 설정에 본인의 Google Gemini API 키를 입력하고 "AI 새 예문" 버튼을 누르면, 그 순간에만 해당 단어·뜻·기존 예문·사용자가 적은 요청 문구가 Google의 Gemini API(generativelanguage.googleapis.com)로 전송되어 새 예문을 받아옵니다. 전송된 내용의 처리는 Google의 Gemini API 이용약관과 개인정보처리방침을 따릅니다. API 키는 사용자의 기기 내부 저장소에만 저장되며 백업 파일에도 포함되지 않습니다. 키를 입력하지 않으면 앱은 네트워크에 접속하지 않습니다.

2-2. 회화 연습 (선택 기능)

회화 연습에서 마이크 버튼을 누르면 기기에 내장된 음성 인식 서비스(대개 Google)가 말을 텍스트로 바꿉니다. 앱은 오디오를 저장하거나 자체 서버로 보내지 않으며, 인식된 문장과 대화 내용만 사용자의 Gemini API 키로 Google Gemini API에 전송되어 답변·한국어 번역·교정을 받습니다. "한국어로 말하기"를 쓰면 인식된 한국어 문장이 영어로 옮기기 위해 같은 방식으로 전송됩니다. 마이크 권한(RECORD_AUDIO)은 이 기능을 처음 쓸 때 요청되며, 거부해도 텍스트 입력으로 연습할 수 있습니다.

2-3. 단어 추가 시 AI 채우기 (선택 기능)

여러 단어를 붙여넣어 추가할 때 "AI로 뜻·예문 자동 채우기"를 켜 두면, 뜻이나 예문이 비어 있는 단어 목록이 사용자의 Gemini API 키로 Google Gemini API에 전송되어 뜻·예문·해석을 받아옵니다. 끄면 전송되지 않습니다.

2-4. 유튜브 쉐도잉 (선택 기능)

사용자가 유튜브 영상 링크를 추가하면, 그 영상의 주소가 사용자의 Gemini API 키로 Google Gemini API에 전송되어 영어 문장·한국어 번역·익힐 표현을 받아오고, 영상 제목을 표시하기 위해 YouTube(oEmbed)에 영상 주소를 조회합니다. 뜻을 모르는 단어를 누르면 그 단어와 문장이 같은 방식으로 Gemini API에 전송됩니다. 정리된 문장은 기기 안에만 저장됩니다.

영상 재생에는 YouTube API 서비스(YouTube 임베드 플레이어)를 사용합니다. 플레이어와 썸네일을 불러올 때 YouTube(Google)가 기기 정보와 쿠키·기기 저장소를 통해 정보를 수집할 수 있으며, 이는 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다. 이 기능을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다.

설정 → Google 드라이브 연동을 켜면(v2.28 이상), 사용자가 직접 고른 파일(예: Google 드라이브의 vocab3-sync.json) 하나에 학습 기록(단어·진도·유튜브 정리·설정, Gemini API 키 제외)을 앱이 내려갈 때와 켜져 있는 동안 5분마다 저장합니다. 파일을 드라이브에 올리는 것은 기기의 Google 드라이브 앱이며, 앱은 그 밖의 곳으로 보내지 않습니다. 연동은 언제든 끊을 수 있고, 드라이브의 파일은 사용자가 관리합니다.

GitHub로 배포하는 앱(v2.27 이상)은 앱을 열 때(최대 30분에 한 번) 새 버전이 있는지 GitHub API(api.github.com)에 이 앱의 최신 릴리스 정보를 요청합니다. 이때 GitHub에 기기의 일반적인 통신 정보(IP 주소 등)가 전달되며, 학습 기록 등 개인 정보는 보내지 않습니다. 새 버전 업데이트를 누르면 GitHub에서 APK 파일을 내려받아 안드로이드 설치 화면으로 넘깁니다. 설정 → 앱 업데이트에서 끌 수 있고, Google Play 에서 설치한 앱은 확인하지 않습니다.

GitHub로 배포하는 앱(v2.14 이상)은 유튜브 영상 링크를 추가하거나 "오프라인 저장"을 누르면 그 영상(360p) 파일을 YouTube 서버에서 직접 내려받아 기기 안 앱 전용 저장소에만 저장하고, 앱 안에서만 재생합니다. 이때 YouTube(Google) 서버에 영상 주소와 기기의 일반적인 통신 정보(IP 주소 등)가 전달됩니다. 받은 영상의 문장을 정리하거나 "이어서 정리하기"를 누르면(v2.23 이상), 그 영상의 소리(음성 트랙)를 10분씩 잘라 사용자의 Gemini API 키로 Google Gemini API에 전송해 문장을 받아옵니다 — 유튜브 영상 주소를 보내는 것과 같은 목적이며, 화면(영상)은 보내지 않습니다. 그 밖에 받은 파일과 거기서 만든 소리 크기 정보는 기기 밖으로 보내지 않으며, 영상을 지우거나 앱을 삭제하면 함께 지워집니다. Google Play 등록용 빌드에는 이 기능이 없습니다.

3. 백업 파일

사용자가 "백업 파일 저장" 기능을 사용하면 학습 데이터가 사용자가 직접 선택한 위치(기기 저장소 또는 클라우드 드라이브 앱)에 JSON 파일로 저장됩니다. 이 파일의 보관과 공유는 전적으로 사용자가 관리합니다.

4. 사용하는 기기 기능 및 권한

  • 인터넷(INTERNET): 선택 기능인 AI 예문 생성·회화 연습·유튜브 쉐도잉에서 Google Gemini API를 호출하거나 YouTube 영상을 재생할 때만 사용합니다. 광고·분석·추적 목적의 통신은 없습니다.
  • 앱 설치 요청(REQUEST_INSTALL_PACKAGES, GitHub 배포 APK 만): 앱 자체 업데이트에서 새 버전 APK 를 설치 화면에 넘길 때만 씁니다. Google Play 빌드에는 없습니다.
  • 마이크(RECORD_AUDIO): 회화 연습의 말하기 입력(기기 음성 인식)에만 사용합니다. 오디오는 저장·전송되지 않습니다.
  • 진동(VIBRATE): 카드를 넘길 때 짧은 햅틱 피드백을 주기 위해 사용합니다.
  • 포그라운드 서비스·알림·절전 방지(FOREGROUND_SERVICE_MEDIA_PLAYBACK, POST_NOTIFICATIONS, WAKE_LOCK): 듣기 복습을 화면이 꺼진 상태에서도 이어서 재생하고 알림으로 제어하기 위해서만 사용합니다.
  • 텍스트 음성 변환(TTS): 기기에 설치된 음성 엔진으로 단어와 예문을 읽어 줍니다. 앱이 음성 데이터를 저장하거나 전송하지 않습니다.

5. 제3자 서비스, 광고, 분석

앱에는 광고, 분석(애널리틱스) 도구, 제3자 SDK가 포함되어 있지 않습니다. 유튜브 쉐도잉 화면을 열 때만 YouTube 임베드 플레이어(YouTube API 서비스)를 불러오며, 그 플레이어 안의 동작은 위 2-4의 YouTube·Google 정책을 따릅니다.

6. 아동의 개인정보

앱은 어떠한 사용자로부터도 개인정보를 수집하지 않으므로 아동의 개인정보 역시 수집하지 않습니다.

7. 데이터 삭제

앱 설정의 "전체 초기화"를 실행하거나 앱을 삭제하면 기기에 저장된 모든 데이터가 삭제됩니다.
